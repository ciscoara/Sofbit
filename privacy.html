Política de Privacidad

Última actualización:

Esta Política de Privacidad explica cómo Sofbit SpA ("nosotros") recopila, usa y protege tus datos personales cuando visitas nuestro sitio web o utilizas nuestros servicios.

Información que recopilamos

  • Información de contacto que proporcionas (nombre, correo electrónico) a través de formularios o comunicaciones.
  • Enlaces profesionales (LinkedIn, GitHub) para fines de contratación y colaboración.
  • Datos no personales (tipo de navegador, páginas visitadas, información del dispositivo) para mejorar la experiencia de usuario.

Cómo usamos la información

  • Para responder consultas, postulaciones laborales o solicitudes de proyectos.
  • Para evaluar candidaturas y proveer servicios.
  • Para mejorar nuestro sitio web, comunicación y experiencia de usuario.

Compartición de datos

No vendemos ni arrendamos datos personales. Podemos compartir información con proveedores de confianza que asisten en nuestras operaciones (por ejemplo, agendamiento, hosting, analítica) y cumplir con las leyes aplicables cuando sea necesario.

Retención de datos

Conservamos la información solo por el tiempo necesario para su propósito y la eliminamos cuando ya no es necesaria.

Seguridad

Utilizamos medidas técnicas y organizativas razonables para proteger tu información, aunque ningún sistema es completamente seguro.

Cambios

Podemos actualizar esta política periódicamente. Las actualizaciones se publicarán en esta página con una nueva fecha de vigencia.
